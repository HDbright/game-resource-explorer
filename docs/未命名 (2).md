多语种沉浸式在线教育平台开发完整需求提示词（完善版）
开发一款多语种沉浸式在线教育平台，主打趣味化、个性化、游戏化沉浸式语言学习体验，核心覆盖英语、日语、韩语等主流外语语种，同时兼容语文、数学、体育等全科学习数据统计与管理。平台面向学生用户、家长用户双端使用，融合系统化课程学习、智能数据追踪、趣味养成玩法、社区激励、家长管控赋能等多重能力，打造轻量化、高互动、高粘性的在线学习场景，完整开发需求如下：
一、核心基础学习能力（平台核心功能）
搭建标准化、体系化的多语种学习架构，满足全阶段用户语言学习需求，基础核心能力全覆盖：
1. 分级课程体系：根据用户年龄、语言基础、学习等级划分零基础、入门、进阶、高阶等多层级课程，课程内容循序渐进，适配不同学习阶段用户，支持多语种独立分级管理。
2. 全场景互动式学习模块：集成多元化轻量化学习功能，包含智能单词记忆、专项语法练习、AI口语跟读纠音、沉浸式听力训练四大核心模块，支持碎片化学习，全程互动打卡、即时校验学习成果。
3. 精细化学习进度追踪：实时记录用户所有课程学习、习题练习、任务完成数据，可视化展示学习时长、完成进度、薄弱知识点、学习频次，支持全程数据溯源。
4. 标准化用户账号体系：支持学生、家长多角色注册、登录、账号绑定、信息管理，区分权限端口，保障双端独立操作、数据互通。
5. AI个性化学习路径推荐：基于用户学习等级、错题数据、薄弱知识点、学习习惯，智能匹配专属学习计划、课程内容、专项练习，实现千人千面的定制化学习方案。
6. 社区交流与成就激励系统：搭建用户学习社区，支持学习心得分享、打卡互动、同伴交流；配套完整成就激励体系，通过勋章、称号、积分、道具等形式激励用户持续学习。
二、家长端专属功能
1. 学习计划编辑权限：家长模式支持查看、编辑、修改已发布的学生学习计划，可灵活调整学习任务、学习时长、学习频次、任务难度，适配学生实时学习状态。
2. 自定义奖励发放功能：家长可手动为学生发放奖励，支持奖励类型包含金币、钻石、专属特殊道具；发放时可填写奖励原因、补充备注说明，实现针对性鼓励式教育。
3. 学习任务奖励规则配置：家长可自主配置各类学习计划、学习任务的奖励机制，自定义不同任务对应的金币、钻石、道具奖励额度，灵活制定激励规则。
三、页面顶部核心数据展示模块（全局顶栏）
平台所有页面顶栏统一固定展示用户核心成长数据，直观呈现学习成果与成长进度，展示内容包含：
1. 用户所持金币数量、钻石数量实时数值；
2. 用户当前角色等级，搭配可视化下一等级进度条；
3. 当前已获得学分、升级所需总学分，清晰展示等级升级缺口。
四、数据统计与奖励记录系统
1. 全科学习成长统计页面：独立的学习成就统计页面，覆盖体育、语文、数学、英语等全学科，通过均衡成长图表可视化展示各学科学习时长、掌握程度、进步幅度、均衡度，直观呈现学生全科学习状态。
2. 完整奖励获得记录：系统自动留存所有奖励获取数据，每条记录完整包含：奖励获得原因、奖励数量、对应学习项目、补充备注信息，支持用户和家长随时查询溯源。
五、特色趣味学习玩法（游戏化养成体系）
1. 智慧树成长系统：平台主页固定展示智慧树图标，点击可独立进入智慧树专属页面。智慧树为动态成长体系，每日根据用户学习等级、学习任务完成质量、学习时长自动产出金币、智慧果资源；用户可每日手动摘取智慧果、拾取树上掉落金币，实现学习即创收的趣味激励。
2. 可收缩智能任务导航条：页面侧边配置可收缩导航组件，默认收缩为迷你图标，存在未完成学习任务时，图标显示小红点消息提示；点击图标可展开悬浮式简洁任务导引列表，展示所有待完成任务；点击列表内对应任务，可直接跳转至对应学习任务页面，实现一键直达、高效学习。
六、个人中心与角色属性系统
1. 自定义头像与个人详情页：支持用户自由更换头像，点击头像可进入完整个人详情页面，集中展示用户所有成长数据与权益。
2. 个人荣誉与装扮展示：详情页展示用户全部学习成就、专属称号、解锁勋章、已穿戴的角色服装与专属道具。
3. 多维角色属性数值：配置专属角色基础属性体系，包含智慧、力量、毅力、敏捷、幸运五大基础数值；同时配套战斗属性数值：攻击、防御、法力，所有数值随学习任务完成、成就解锁、等级提升动态增长。
七、全套养成与商城体系
平台集成完整的游戏化养成、资产、交易体系，提升用户粘性，功能全覆盖：
1. 宠物系统：支持宠物解锁、培养、升级、陪伴学习，宠物可跟随用户学习成长，解锁专属技能与外观；
2. 英雄系统：开放英雄角色解锁、养成、升级、进阶功能，英雄等级、战力与用户学习等级、学习成果绑定；
3. 背包系统：统一收纳用户所有金币、钻石、服装、道具、智慧果、专属奖励等资产，支持查看、使用、管理所有道具；
4. 商店系统：搭建平台专属商城，支持使用金币、钻石兑换各类服装、道具、宠物物资、学习权益、专属课程等内容。
八、整体产品要求
整体平台以沉浸式、趣味化、系统化、数据化为核心，兼顾多语种专业学习与全科学习管理，通过游戏化养成玩法降低学习门槛、提升用户学习主动性，同时为家长提供可视化管控、个性化激励能力，实现“趣味学习+科学管控+持续激励”的完整闭环，页面交互简洁流畅、数据实时同步、权限区分清晰，适配移动端、网页端在线使用。
