# 得乐学苑开发文档

## 功能说明
### 积分奖励和晋级制度
  一、积分获取方法


开发一款支持多语种学习的在线教育平台，涵盖英语、日语、韩语等主流语言。平台需打造沉浸式语言学习体验，提供以下能力：
1、分级课程体系
2、互动式学习模块（单词记忆、语法练习、口语跟读、听力训练）
3、学习进度追踪功能
4、支持用户注册登录
5、个性化学习路径推荐
6、社区交流及成就激励系统

●家长模式可修改已发布学习计划的功能.
●顶栏显示已获得金币数量钻石数量，角色等级和下一等级进度条和已获得学分/升级所需学分显示
●学习成就统计页面,体育,语文,数学,英语各科的成长均衡图表
奖励获得记录(获得原因,数量,项目,备注)
●家长发放奖励功能(奖励金币,钻石,特殊道具,原因,备注)
●学习计划设定的学习任务的奖励规则
●主页有智慧树图标,点击该图标进入智慧树页面,智意树每日根据用户的学习等级和任务完成情况可产生金币和智慧果,用户可摘取每日智慧果和树上掉落的金币.
●页面有可收缩成一个图标的任务导航条,有待完成有小红点提示.点击图标可展开成悬浮的简洁任务导引列表.点击列表中的某些任务则直接调转到任务页面.
●头像可更换,点击头像进入个人详情页面,各项学习成就,获得的称号,勋章,穿戴的服装和道具，基础数值(智慧,力量,毅力,敏捷,幸运)攻击,防御,法力的数值.
●宠物,英雄,背包,商店功能都要有
