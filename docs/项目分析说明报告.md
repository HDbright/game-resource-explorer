## 1. 项目架构总览

**进程模型**

```
主进程 electron/main.js → preload.js 桥接 → 渲染进程 (index.html + src/*)
```

- **主进程**：窗口创建、内部 HTTP 静态服务、SQLite 持久化（`electron/db.js`）、资源扫描（`scanner.js`）、缩略图磁盘缓存 IPC、冒烟测试驱动。
- **渲染进程**：全部界面与交互。模块化 ES Module，由 `src/main.js` 启动。
- **状态层**：`src/state.js` 集中管理分类/资源/设置，提供派生查询函数；任何改动后调用 `saveState()` 防抖写库。
- **预览引擎**：PixiJS 8.9.2 渲染；Spine 4.x / Spine 3.8 / DragonBones 三个播放器 + 版本探测路由（`src/preview/`）。

> ⚠️ **三条最重要的工程约束（改代码前必读）**
>
> 1. **pixi.js 必须锁 8.9.2**，不可随意升级（spine-pixi 2.1.1 依赖，8.19+ 会崩）。
> 2. **进入预览页必须强制 `preview._resize()`**；三个预览子视图（`#pv-anim-view / #pv-image-view / #pv-audio-view`）必须保持 `flex:1; display:flex; flex-direction:column; min-height:0`，否则画布高度塌陷为 0、动画空白。
> 3. 状态由 `state.settings.resourceTab` 决定右侧显示「全局主页 / 类型主页 / 目录列表页 / 预览页」，修改导航逻辑时注意 `renderMainArea()` 的分支判断。

## 2. 界面布局总图

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [☰ 资源树]  游戏资源管理器   主页 / 动画主页 / 分类名…    [搜索框][+添加资源][+批量添加][新建分类] │  ← 顶栏 .toolbar (index.html 第11-25行)
├──────────────────────────────────────────────────────────────────────────────┤
│ ┌─ 左侧侧栏 .sidebar (#sidebar) ─┐┌─ 右侧主内容区 .content-panel (#content-panel) ──────────────┐
│ │ 动画│图片│音频│3D  (标签)      ││ 三个页面 (hidden 切换)                                     │
│ │ ─────────────────────         ││  ┌─ #page-home     全局主页(统计卡片/目录快捷/最近添加)     │
│ │ 分类树 #cat-tree:              ││  ├─ #page-home     类型主页(统计+分类目录树) ←复用home容器 │
│ │   ▦ 全部动画(类型主页链接)      ││  ├─ #page-folder   目录列表页(统计/三视图/排序/编辑模式)    │
│ │   ○ 未分类                     ││  └─ #page-preview  预览页(动画/图片/音频三子视图)           │
│ │   ▣ 分类A ▶                    ││                                                                   │
│ │   ▣ 分类B ▼                    ││                                                                   │
│ │     ▣ 子分类                   ││                                                                   │
│ │   ★ 收藏夹                     ││                                                                   │
│ └───────────────────────────────┘└───────────────────────────────────────────────────┘
```

### 页面显示逻辑（renderMainArea 分支）

```text
state.settings.resourceTab 取值 → 右侧显示什么
  'home' / 'all'  ───────────────────────→  #page-home  全局主页
  'anim'|'image'|'audio'|'3d' 且 currentCategoryId 为 'all'  →  #page-home  类型主页(动画主页/图片主页/…)
  'anim'|'image'|'audio'|'3d' 且 currentCategoryId 为具体分类 →  #page-folder  目录列表页
  任何类型,点击资源条目 ─────────────────→  #page-preview  预览页
```

## 4. 左侧资源树侧栏（.sidebar）

位置：`index.html` 第 28–37 行；样式 `style.css` 第 97 行起；渲染 `src/ui.js` 的 `renderTree()`（第 125 行）。

### 4.1 类型标签区 #resource-tabs

| 标签 | data-tab | 点击行为 |
|---|---|---|
| 动画 | `anim` | 切 resourceTab + currentCategoryId='all' → 右侧显示对应**类型主页**；标签高亮当前类型（accent 蓝底） |
| 图片 | `image` | 同上 |
| 音频 | `audio` | 同上 |
| 3D | `3d` | 同上 |

> 注：没有「主页」标签。全局主页入口 = 品牌名 + 面包屑「主页」。若想加回主页标签，修改 index.html 的 #resource-tabs 并在 `bindTabs()` 加分支。

### 4.2 分类树 #cat-tree

树节点结构（由 `renderPseudoNode()` / `renderCatNode()` / `renderFavSection()` 生成）：

| 节点 | 图标/箭头 | 点击行为 | 右键菜单 |
|---|---|---|---|
| ▦ 全部XX（伪节点 id='all'） | 箭头显示 **→**（链接样式） | 打开该类型主页（全部资源列表页），**不展开**树内条目 | — |
| ○ 未分类（伪节点 id=''） | ▶/▼ | 点名称只选中并切目录页；**只有点箭头才展开** | 无 |
| ▣ 分类节点（id=分类id） | ▶/▼（·表示空） | 点名称只选中 + 右侧切目录列表页；**点箭头才展开/折叠**；默认全部折叠（v1.4.4 起） | 添加资源/批量添加/新建子类别/编辑分类/移动.../删除 |
| 条目节点（.item-node） | 类型徽章 | 点击预览；**右键**弹条目菜单 | 播放/打开目录/编辑/移动到.../删除/属性 |
| ★ 收藏夹（fav: 前缀） | ▶/▼ | 同分类节点；收藏分类可拖入条目 | 新建收藏分类/改名/删除 |

- **展开状态**存于 `expandedCats`（Set）；**默认只展开收藏夹根**，所有分类折叠。
- **拖拽**：条目拖到分类 = 移动资源；分类拖到分类中部 = 设为子分类、边缘 = 同级排序；收藏夹区域支持拖入收藏。
- **箭头热区**已扩大（::before 伪元素 ±8/±10px），手型光标。

## 6. 全局主页（统计页）

渲染 `src/pages/homePage.js` 的 `renderGlobalHome()`；数据 `getHomeData()`（state.js）。结构：

- **标题**「游戏资源管理」+ 副标题（资源总数）。
- **统计卡片 .home-cards**（5 张 .stat-card）：动画资源 / 图片资源 / 音频资源 / 3D 资源 / 资源总数 —— 每张显示数量 + 占用空间，点击卡片 = 切到对应类型主页。
- **📁 目录快捷入口 .quick-cats**：每个顶级分类一个快捷块（名称 + 资源数 + 占用），点击进入该分类目录页。
- **🕘 最近添加 .recent-list**：最近 10 条资源（类型徽章 + 名称 + 分类），点击预览。

## 7. 类型主页

渲染 `homePage.js` 的 `renderTypeHome()`；数据 `getTypeHomeData(group)`（state.js）。

- **标题**「动画主页 / 图片主页 / 音频主页 / 3D 资源主页」+ 副标题（数量/细分/占用）。
- **3 张统计卡片**：资源总数 / 占用空间 / 分类目录数。
- **📁 分类目录（拓扑树 .type-cat-tree）**：递归渲染所有分类的层级结构，缩进表示层级（`--cat-depth` 变量）；每个分类显示名称 + 该类型资源数（含子孙）+ 占用；点 ▶/▼ 折叠展开；**右键 = 分类右键菜单**；展开后显示直属资源条目（点击预览）。
- **🕘 最近添加**：当前类型最近 10 条。

> 类型主页的标题映射在 `homePage.js` 的 `GROUP_TITLE` 常量；统计卡片在 `renderTypeHome()` 中 `cards` 数组。

## 8. 目录列表页（#page-folder）

渲染 `src/pages/folderPage.js` 的 `renderFolderPage()`；数据 `getFolderData()`。从上到下结构：

| 区域 | 内容 |
|---|---|
| **.folder-head** | 文件夹图标 + 当前目录名 + 统计条（共 N 项 · 类型分布 · 占用） |
| **.folder-toolbar** | ① 视图切换（📋详情 / ☰列表 / 🖼图标）② 排序下拉 `#sort-by` + 升/降序按钮 ③ ✎编辑按钮 ④ 编辑模式下：☑全选/☐取消/⇄反选/🗑删除/📂移动 ⑤ 资源计数 |
| **.subcat-row** | 子目录快捷块（点击进入子目录） |
| **.folder-body** | 资源列表主体，三种视图： |
| — 📋 详情视图 .res-table | 名称/类型/大小/修改日期/备注/操作（▶预览 ★收藏 ✎编辑）；表头可点击排序 |
| — ☰ 列表视图 .res-view-list | 横向行：徽章+名称+大小+日期+操作 |
| — 🖼 图标视图 .res-grid | 卡片网格：缩略图（动画用离屏渲染 dataURL/图片直连 URL/音频♪/3D🧊）+ 名称 + 徽章；缩略图有**磁盘缓存**加速 |

### 8.1 排序与视图

- 排序字段：名称/类型/大小/修改日期；方向升/降。**下拉框用 change 事件**（click 会导致下拉闪没，已修复）。
- 视图与排序选择持久化在 `settings.listViewMode / listSortBy / listSortDir`。

### 8.2 编辑模式（批量操作）

- 点「✎ 编辑」进入编辑模式（`editModeActive` + `editSelected` Set 在 ui.js）。
- 编辑模式下：点击条目 = 选中/取消（不进预览）；**全选/取消/反选**一键操作；选中行高亮 + 左侧蓝条 + ☑ 标记。
- **🗑 删除**：确认后批量从列表移除（不删磁盘文件）。
- **📂 移动**：弹窗选择目标分类（含层级路径），批量修改分类归属。

> **3D 模型预览**：暂未内置 3D 渲染器，点击 3D 模型文件会在 `#pv-error` 区域显示文件信息占位（文件格式/大小/路径），并提示可通过「打开目录」查看文件。

## 10. 弹窗 / 右键菜单 / 拖拽系统

### 10.1 弹窗系统

统一封装在 `src/dialogs.js`：`openModal()`、`confirmDialog()`、`promptDialog()`、`toast()`、`showContextMenu()`。弹窗挂载于 `#modal-root`。宽弹窗用 `.modal.wide`（680px）。

### 10.2 常用弹窗清单

| 弹窗 | 触发 | 函数 |
|---|---|---|
| 新建分类 | 顶栏「新建分类」 | `newCategoryDialog()` |
| 编辑分类 / 删除分类(高级) | 分类右键菜单 | `editCategoryDialog() / deleteCategoryDialog()` |
| 移动分类 | 分类右键「移动...」 | `moveCategoryDialog()` |
| 添加资源向导 | 顶栏「+添加资源/+批量添加」、空态按钮、右键 | `runAddFlow()`（addFlow.js：选文件/选目录 → 重名去重 → 导入） |
| 条目属性 / 编辑 / 移动 / 删除 | 条目右键菜单 / 列表操作列 | `itemPropertiesDialog() / editItemDialog() / moveItemDialog() / deleteItemDialog()` |
| 收藏目标选择 | 条目右键「收藏」、列表 ★ | `collectTargetDialog()` |
| 批量删除 / 批量移动 | 编辑模式工具栏 | `batchDeleteItems() / batchMoveItems()` |

### 10.3 右键菜单内容

- **分类菜单**：添加资源 · 批量添加 · 新建子类别 · 编辑分类 · 移动... · 删除（`openCategoryMenu()`）
- **条目菜单**：播放 · 打开目录 · 编辑 · 移动到... · 删除 · 属性（`openItemMenu()`）
- **收藏分类菜单**：新建收藏分类/改名/删除

### 10.4 拖拽（drag & drop）

分类树内：条目拖到分类 = 移动；分类拖到分类 = 子分类/排序；收藏夹支持拖入条目。状态操作函数在 state.js（`reorderCategory / updateItem / moveFavItem` 等）。

## 12. 修改 UI 与功能的操作指南

### 🎨 A. 修改界面外观（颜色/间距/尺寸/字体）

1. 打开 `src/style.css`，按顶部区块注释找到对应类（如改顶栏 → `.toolbar`；改卡片 → `.stat-card`；改列表 → `.res-*`）。
2. 主题色变量在文件最上方 `:root`（--bg/--text/--accent 等），全局改色只需改这里。
3. 改完运行 `npm run build` 或直接看 dev 预览（vite）。

### 🧩 B. 调整界面布局（位置/顺序/增删区域）

1. 静态结构在 `index.html`：如调整顶栏按钮顺序、给侧栏加区块、给预览页加控件，直接改 HTML。
2. 动态生成的内容（主页卡片、分类树、列表、类型主页目录树）在各渲染函数里（见第 11 节对照表）。
3. 改完后若元素是动态渲染的，需要同步修改对应 JS 模板字符串；若只改静态部分，CSS+HTML 即可。

### ⚙️ C. 修改功能行为（点击/跳转/数据）

1. 交互逻辑集中在 `src/ui.js`（绑定函数）与 `src/state.js`（数据操作）。
2. 导航/页面切换：改 `renderMainArea()` 分支 + `showPage()`。
3. 数据统计/查询：改 `state.js` 的 `getHomeData / getTypeHomeData / getFolderData`。
4. 资源类型扩展（如新增类型）：需要动 scanner 扩展名表、TYPE_GROUPS、TYPE_LABEL、各渲染函数、预览分发 `selectItem`。

### 🧪 D. 验证修改（冒烟测试）

1. 运行 `npm run smoke` 自动验证约 40 个功能点（渲染/CRUD/预览/编辑模式等），截图存 `%TEMP%/skeleton-previewer-smoke/`。
2. 冒烟步骤定义在 `src/main.js` 的 `__smokeStep` case 中；步骤顺序在 `electron/main.js` 的 steps 数组。
3. 打包：`node scripts/pack-manual.js`（勿用 electron-builder，本机 Defender 会卡死）。
