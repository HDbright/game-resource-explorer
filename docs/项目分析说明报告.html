1. 项目架构总览

进程模型
主进程 electron/main.js→ preload.js 桥接→ 渲染进程 (index.html + src/*)
  • 主进程：窗口创建、内部 HTTP 静态服务、SQLite 持久化(electron/db.js)、资源扫描(scanner.js)、缩略图磁盘缓存 IPC、冒烟测试驱动。
  • 渲染进程：全部界面与交互。模块化 ES Module，由 src/main.js 启动。
  • 状态层：src/state.js 集中管理分类/资源/设置，提供派生查询函数；任何改动后调用 saveState() 防抖写库。
  • 预览引擎：PixiJS 8.9.2 渲染；Spine 4.x / Spine 3.8 / DragonBones 三个播放器 + 版本探测路由(src/preview/)。
⚠️ 三条最重要的工程约束(改代码前必读)
  1. pixi.js 必须锁 8.9.2，不可随意升级（spine-pixi 2.1.1 依赖，8.19+ 会崩）。
  2. 进入预览页必须强制 preview._resize()；三个预览子视图(#pv-anim-view / #pv-image-view / #pv-audio-view)必须保持 flex:1; display:flex; flex-direction:column; min-height:0，否则画布高度塌陷为 0、动画空白。
  3. 状态由 state.settings.resourceTab 决定右侧显示「全局主页 / 类型主页 / 目录列表页 / 预览页」，修改导航逻辑时注意 renderMainArea() 的分支判断。

4.2 分类树 #cat-tree

树节点结构（由 renderPseudoNode() / renderCatNode() / renderFavSection() 生成）：

节点图标/箭头点击行为右键菜单
▦ 全部XX（伪节点 id='all'）箭头显示 →（链接样式）打开该类型主页（全部资源列表页），不展开树内条目—
○ 未分类（伪节点 id=''）▶/▼点名称只选中并切目录页；只有点箭头才展开无
▣ 分类节点（id=分类id）▶/▼（·表示空）点名称只选中 + 右侧切目录列表页；点箭头才展开/折叠；默认全部折叠（v1.4.4 起）添加资源/批量添加/新建子类别/编辑分类/移动.../删除
条目节点（.item-node）类型徽章点击预览；右键弹条目菜单播放/打开目录/编辑/移动到.../删除/属性
★ 收藏夹（fav: 前缀）▶/▼同分类节点；收藏分类可拖入条目新建收藏分类/改名/删除
  • 展开状态存于 expandedCats（Set）；默认只展开收藏夹根，所有分类折叠。
  • 拖拽：条目拖到分类 = 移动资源；分类拖到分类中部 = 设为子分类、边缘 = 同级排序；收藏夹区域支持拖入收藏。

12. 修改 UI 与功能的操作指南

🎨 A. 修改界面外观（颜色/间距/尺寸/字体）
  1. 打开 src/style.css，按顶部区块注释找到对应类（如改顶栏 → .toolbar；改卡片 → .stat-card；改列表 → .res-*）。
  2. 主题色变量在文件最上方 :root（--bg/--text/--accent 等），全局改色只需改这里。
  3. 改完运行 npm run build 或直接看 dev 预览（vite）。
🧩 B. 调整界面布局（位置/顺序/增删区域）
  1. 静态结构在 index.html：如调整顶栏按钮顺序、给侧栏加区块、给预览页加控件，直接改 HTML。
  2. 动态生成的内容（主页卡片、分类树、列表、类型主页目录树）在各渲染函数里（见第 11 节对照表）。
  3. 改完后若元素是动态渲染的，需要同步修改对应 JS 模板字符串；若只改静态部分，CSS+HTML 即可。
⚙️ C. 修改功能行为（点击/跳转/数据）
  1. 交互逻辑集中在 src/ui.js（绑定函数）与 src/state.js（数据操作）。
  2. 导航/页面切换：改 renderMainArea() 分支 + showPage()。
  3. 数据统计/查询：改 state.js 的 getHomeData/getTypeHomeData/getFolderData。
  4. 资源类型扩展（如新增类型）：需要动 scanner 扩展名表、TYPE_GROUPS、TYPE_LABEL、各渲染函数、预览分发 selectItem。
