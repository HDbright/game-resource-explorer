# 页面组件可视化标注报告 · 生成提示词

> 用途：给任意 AI 助手一份完整指令，让其针对某个前端模块自动产出「组件可视化标注报告」（每个可视组件编号 + 名称 + 代码位置 + 作用，配真实外观还原 + 图例联动），方便人工精准描述与修改布局/功能。
> 用法：把下框内全部内容复制给 AI，并将 `【目标模块中文名】` 和仓库路径替换为你自己的。

---

```
你是一名高级前端开发工程师。请为我的前端项目生成一份「页面组件可视化标注报告」。

【目标模块】"【目标模块中文名】"（例如：得乐学苑 / 小学生成长闯关台）
【仓库路径】E:\MyProject\spine_viewer
【模块源文件】先用 Grep 在仓库中搜索该中文名，定位它实际对应的源文件（例如搜到 "得乐学苑" → 对应 src/pages/kidWorkspacePage.js）。以定位到的源文件为准。

===== 目标 =====
产出一份单文件、可离线打开的 HTML 报告，直观展示该模块每一个可见组件，并标注：
  1) 组件编号（在还原图上叠加红色圆形 pin）
  2) 组件名称
  3) 在源码中的精确位置（渲染函数名 + 行号，例如 renderTaskCard() · L1011）
  4) 组件作用说明
让阅读者能"看图点编号 → 看代码位置 → 直接去改"，无需反复翻源码。

===== 执行步骤 =====
1. 定位与通读：Grep 中文名定位源文件；通读源文件，列出所有可视组件（顶栏、列表、Tab、各主视图、弹窗、抽屉、卡片内部细节等）。
2. 抽取真实 CSS：源文件内通常有一段内联注入的样式（例如 `const CSS = \`...\``）。用脚本（Node）把这段 CSS 原样抽取出来嵌入报告，不要用近似手写样式——必须像素级还原真实外观。
3. 还原多屏：用抽取到的真实 CSS，构造若干"屏幕"区块（如：主框架屏 / 各 Tab 主视图屏 / 弹窗与键盘屏 / 设置抽屉屏 / 部件细节放大屏），用演示数据填充，真实还原组件外观。
4. 叠加编号 pin：每个被标注的组件外层包一个相对定位容器（.pinwrap{position:relative}），左上角放一个绝对定位编号 pin（.pin{position:absolute;top:-13px;left:-13px;...}），pin 上写组件编号。
5. 组件清单总表（图例）：报告右侧（或底部）放一张表，每行 = 编号 / 组件名称 / 代码位置(函数+行号) / 作用说明。点击编号 pin 或图例行时，双向联动：高亮对应项并滚动定位到该组件在报告中的位置。
6. 写生成脚本：把上述逻辑写成 scripts/gen-xxx-annotation-report.js，HTML 由脚本生成（方便以后源码变更时重跑刷新）。报告本身不改版本号、不打包，仅文档交付（除非我另有要求）。
7. 校验：生成后检查 ① 无未闭合 HTML 标签 ② 所有 pin 与图例行数量一致、全覆盖 ③ 无 \${ 模板残留 ④ 用无头/静态方式确认布局无遮挡。

===== 关键约束与常见坑（务必遵守）=====
- ⚠️ 弹窗遮罩 .kid-overlay（真实 CSS 多为 `position:fixed; inset:0; z-index:9990; background:rgba(...,.45)` 全屏遮罩）和抽屉 .kid-drawer（`position:fixed` 全屏）在本报告里被当作静态内容渲染时，必须把它们降级为 `position:relative` 并清除 inset/z-index/background/backdrop-filter，否则会以 fixed 脱离文档流钉在视口上，盖住整页导致无法浏览。可在注入真实 CSS 之后追加一段报告专用 override（`.kid-wb .kid-overlay/.kid-drawer/.kid-toast-ok{position:relative!important; ...}`）来覆盖。
- 报告内示例数据一律用占位演示数据，并在报告顶部注明"示例数据为演示用"。
- 保持单文件 HTML、零外部依赖、可离线打开。
- 交付时给出：报告文件路径 + 生成脚本路径 + 覆盖的屏幕数与组件数 + 如何使用（点编号看代码位置）。

===== 交付物 =====
- docs/xxx-component-report.html（报告，单文件）
- scripts/gen-xxx-annotation-report.js（生成器，可重跑）
```

## 本仓库实际落地参数（供参考，已验证可复现）
- 模块中文名：得乐学苑 → 源文件 `src/pages/kidWorkspacePage.js`
- 抽取的真实样式：源文件内 `const CSS = \`...\`` 整段
- 报告：`docs/kid-workspace-component-report.html`；生成器：`scripts/gen-kid-annotation-report.js`
- 覆盖：7 个屏幕、35 个编号组件（含弹窗/抽屉/卡片细节放大）
- 已修复的坑：弹窗遮罩与抽屉的 `position:fixed` 在报告中降级为 `position:relative`，否则整页被遮挡
- 联动：点击编号 pin 或右侧图例行 → 高亮 + 滚动定位
