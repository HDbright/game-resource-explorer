# 游戏资源管理器 — 全面布局与组件说明

> 对象：游戏资源管理器（Electron 桌面应用，v1.8.1）
> 定位：管理并预览 **动画(Spine/DragonBones) / 图片 / 音频 / 3D(model)** 四类游戏资源；内置资源工具箱（FGUI 逆向导出、FGUI 编辑器、ASTC→PNG、SKEL→JSON、Spine 修复、图片编辑）；游戏场景管理（含 FGUI 界面预览器）；**网络资源抓取**（内嵌浏览器逆向分析并下载 FGUI/Spine/图集/图片/音频 等资源入库）；网址收藏夹；系统设置。
> 技术栈：Electron + Vite + 原生 JS(ESM)；渲染 PixiJS 8（动画/图片/FGUI 画布）、DOM overlay（文本）、WebContentsView（内嵌网页）；数据持久化 better-sqlite3。

---

## 一、应用架构与数据流

```
Electron 主进程(electron/main.js + electron/tools/*)
   ├─ 窗口/菜单/文件对话框(shell, dialog)
   ├─ IPC 通道(db:read/write, fs:*, tool:*, fgui:*, audio:*, thumb:*, web:* …)
   ├─ 资源扫描(electron/scanner.js: Spine/DB/图片/音频/3D/FGUI 识别)
   ├─ 转换工具(ASTC→PNG、SKEL→JSON、Spine 修复)
   ├─ FGUI 逆向(fgui/index.js: 探测/解析/导出/源工程还原) + 预览数据(previewData.js)
   ├─ 网络资源抓取(tools/webGame.js: WebContentsView 单例 + 请求拦截分类 + 下载入库)
   └─ SQLite 库(data/skeleton.db: items/categories/fav_*/scenes/web_bookmark_* 等)

渲染进程(src/**: main.js 入口 → state.js 状态 → ui.js 布局与导航 → pages/*.js 各页面 → viewers/*.js 查看器)
   └─ index.html: 单一 #app → 顶栏 + 侧栏 + #content-panel(9 个 page 容器)
```

数据流：`state.js`(内存) ⇄ `window.api.dbRead/dbWrite`(IPC) ⇄ SQLite；所有增删改经 `saveState()` 防抖 150ms 写盘。
网络抓取数据流：`tools/webGame.js` 拦截 WebContentsView 网络请求 → `classify` 分类 → `onWebCaptured` 推送渲染进程列表 → 选中/批量 `downloadResource`(主进程 https 下载) → `addScene`(subtype='fgui') / `addItem` 入库。

### 2.1 顶栏
| id | 控件 | 功能 |
|---|---|---|
| `#btn-toggle-side` | 侧栏开关 | 显示/隐藏侧栏（localStorage 记忆） |
| 品牌名 | 首页入口 | 点击回资源首页（`resourceTab='home'`，清空一切覆盖页状态） |
| `#breadcrumb` | 面包屑 | 当前页路径（如 资源首页 › 动画 › 某分类） |
| `#search` | 全局搜索框 | 在目录页过滤资源（名称/属性/标签）；`#search-clear` 清空 |
| `#btn-add` | + 添加资源 | 打开添加流程（文件/目录扫描识别资源类型） |
| `#btn-add-batch` | + 批量添加 | 批量导入 |
| `#btn-settings` | ⚙ 设置 | 打开系统设置页 |
| `#resource-tabs` | 资源标签 | 动画/图片/音频/3D 四个类型 tab；当前 tab 高亮，主区切到类型主页/目录 |

### 2.2 侧栏分类树 `#cat-tree`
- **类型根节点**（id=`all`，名称随 tab：动画资源/图片资源/…/资源）：类型主页链接 + 展开/折叠该类型分类目录（默认展开）
- **分类节点**：递归展开子分类/直属条目；条目单击 → 预览（FGUI 包直达预览）；右键菜单（打开/新建目录/编辑/删除/移动/重命名…）
- **未分类节点**：无分类条目
- **收藏夹根** `__fav__`：收藏分类树
- **资源工具箱根** `__tools__`：文件格式转换（astc→png / skel→json / spine 修复）、图片编辑、**FGUI导出**（逆向导出）、**FGUI编辑器**（独立可视化编辑器入口 `__fgui_editor__`）
- **游戏场景管理根** `__scene__`：场景分类树 + FGUI 界面预览入口；FGUI 包(.bin)条目点击/右键「✏️ 用FGUI编辑器打开」
- **网络资源抓取根** `__webgame__`：内嵌浏览器逆向抓取资源入口；下含「🕹 最近打开」(`webGameHistory` 子节点，点击直达回填 URL) 与「🔖 网址收藏夹」分类树(`__webgame_fav__`，可嵌套子目录，默认展开，条目可增删改查)
- 树节点构造器 `makeTreeNode`：▶/▼ 箭头 + 图标 + 名称 + 数量
- 网络抓取根节点右键：打开抓取页 / 新建收藏夹目录 / 清空捕获记录；网址收藏夹分类节点右键：打开收藏夹 / 新建子目录 / 编辑目录 / 删除目录

### 2.3 主内容区页面容器
`page-home` / `page-audio-home` / `page-folder` / `page-preview` / `page-toolbox` / `page-scene` / `page-fgui-editor` / `page-webgame` / `page-settings`（`showPage()` 切换）。其中 `page-fgui-editor` 与 `page-webgame` 为新增独立页：
- `page-fgui-editor`：FGUI 编辑器（IDE 式布局，复用 FguiLayoutPreview 画布引擎，详 **十四、FGUI 编辑器模块**）
- `page-webgame`：网络资源抓取（内嵌 WebContentsView 叠加于该页容器之上，详 **十五、网络资源抓取模块**）

### 2.4 主区多标签页（v1.6.9+）
- 主内容区顶部新增标签条 `#tab-strip`（`.main-tab` 项：图标 + 名称 + **悬停显示的关闭符号 ×**）
- **打开资源 = 新标签页**（资源名 + 类型图标 🎬🖼♪🧊）；点击类型/目录/工具箱/场景/设置/首页等导航 = 切换到对应标签页，原标签保留可随时切回
- 关闭当前标签自动切到相邻标签；全部关闭回首页
- 标签同步：`renderMainArea` 渲染前 `syncTabFromState()` 自动对齐；`ensureTab/switchTab/closeTab/applyTabState` 管理生命周期；修复 FGUI 预览时点「全部资源首页」无法切换的问题

## 五、预览页（page-preview）

顶部条：返回 `#pv-back` / 类型 `#pv-type` / 名称 `#pv-name` / 版本 / 路径 `#pv-path` / 打开目录 `#pv-open-dir` / 刷新 `#pv-reload`；下方三子视图按类型切换（`#pv-anim-view` / `#pv-image-view` / `#pv-audio-view` / `#pv-fgui-view`(旧版 FGUI)）。

### 5.1 动画预览（Spine/DragonBones，PixiJS）
- 控制条：播放/暂停 `#btn-play`、重启 `#btn-restart`、速度 `#speed-range`、缩放 `#zoom-range`+模式(`fit/100%/fixed`) `#zoom-mode`、帧导航 `#frame-*`、动画切换 `#anim-select`、背景色 `#bg-*`、显示骨骼 `#show-bones`、水平翻转 `#flip-x`、旋转 `#btn-rotate`、截图 `#pv-capture`
- 运行时路由：3.x → Spine38Player(vendor/spine38)；4.x → SpinePlayer(@pixi/spine-pixi)；DragonBones → vendor/dragonbones

### 5.2 图片查看
缩放 `#img-zoom-range`、适配/原始大小、背景色、状态栏

### 5.3 音频播放器（AudioPlayerController）
单曲/目录/播放列表队列，6 模式，变速 `#audio-rate`，ID3 编辑，迷你条 `#audio-mini`（离开预览后台播放）

### 5.4 3D 模型
占位视图（showModelPlaceholder，无内置渲染器）

## 十四、FGUI 编辑器模块（page-fgui-editor）

> 代码：`src/pages/fguiEditorPage.js`（页面/工具栏/事件）、`src/viewers/fguiLayoutPreview.js`（PixiJS 渲染与交互，与预览器共用）、`src/style.css`（`.fge-*` 样式）
> 入口：左侧「资源工具箱」→「FGUI编辑器」菜单（`enterFguiEditor`）；场景管理中 FGUI 包(.bin)条目点击/右键「✏️ 用FGUI编辑器打开」→`openFguiEditorFromScene`；最近打开记录 FGUI 项点击。
> 定位：**独立于 FGUI 界面预览器**的可视化编辑器，布局参考 FairyGUI-Editor-Online 的 IDE 结构（顶栏 + 左资源面板 + 中画布 + 右属性）。复用 FguiLayoutPreview 画布引擎与 `fguiPreviewLoad` 数据层。

### 14.3 左资源面板（②区）
两个 tab（`.fge-tab`）：
- **🧩 组件树**：上半「组件列表」(`#fge-complist`，列出包内全部组件 `名称 (宽×高)`) + 中间 `#fge-hsplit` 分割线（可上下拖动调组件列表/层级树高度比） + 下半「层级树」(`#fge-hier`，按深度缩进列出当前组件所有节点，箭头可折叠/展开，点击与画布选中联动，折叠状态提示 `N 处折叠`)。
- **🗂 资源**：四个子 tab（`.fge-rtab`）：🖼 图片 / 🔤 字体 / 🎞 动画 / 🔊 声音；列表 `#fge-reslist` 显示该类型全部资源（路径/尺寸）；点击资源 → 主区 `#fge-canvas` 中**使用该资源的节点 9 点高亮**(`highlightResource`) + 右侧属性面板显示资源属性 + 下方「资源预览」区(`#fge-res-pv-body`)：图片按 sprite 裁剪渲染（rotated 逆时针转回）、字体/动画展示信息、声音提供「▶ 播放」按钮。

### 14.4 画布区（③区）与右面板（④区）
- 画布：复用 FguiLayoutPreview（PixiJS 独立 App，`ticker.stop()` + 手动 render），`#fge-text` 文本 DOM 叠加层（天然支持中文/换行/选中框）。支持滚轮缩放、拖拽平移、点选高亮、编辑模式拖拽/缩放/双击文本内联编辑、Ctrl+Z 撤销。
- 右侧面板：顶部「控制器」(`#fge-ctrls`，每个控制器一组页名按钮，切换控制器页并按 gearDisplay 重算可见性) + 下方「属性」(`#fge-props`，点击画布/层级树对象后显示；v1.7.16 起名称/id 可编辑、srcPkg/sprite/atlas 字段可一键复制)。

### 14.5 状态保持与联动
- 页面首次进入初始化一次（`container._fguiEditorInited` 标记），切到其它菜单/标签页再回来时**保留已打开的包、组件与编辑状态**，不重建画布；外部再次加载走 `container._fguiEditorLoad(binPath)`。
- 保存源工程（`fguiSaveSourceEdits`）：几何属性全量提交，名称/id 增量提交（对比 `nodeOrig` 快照），并全局替换引用；写回 `FGUI_src/<包名>/<组件>.xml`。
- 侧栏 FGUI 包条目联动：点击/右键「用FGUI编辑器打开」经 `openFguiEditorFromScene` 触发 `enterFguiEditor(binPath)`。

## 十五、网络资源抓取模块（page-webgame）

> 代码：`src/pages/webGamePage.js`（页面 UI/入库/收藏夹）、`electron/tools/webGame.js`（`WebGameView` 单例：open/setBounds/close/destroy + `hookWebRequest` 请求拦截 + `classify` 分类 + `downloadResource` 下载 + `probeFile` 本地探测）、`electron/main.js`（web:* IPC）、`electron/preload.js`（10 个 invoke + 4 个事件）、`src/style.css`（`.wg-*` 样式）
> 入口：左侧「🌐 网络资源抓取」根节点（`enterWebGame`）；根下「🕹 最近打开」子节点（点击回填 URL 并打开）；「🔖 网址收藏夹」分类树（点击切到收藏夹面板）。
> 定位：内嵌真实网页（WebContentsView，Electron 43 推荐的 BrowserView 替代方案，独立 `persist:webgame` session 持久化登录态），拦截所有帧（含 4399 登录 iframe）的网络请求，自动分类为 FGUI/Spine/图集/图片/音频/视频/字体/脚本/配置，**下载并按类型入库**（`fgui .bin → addScene(subtype='fgui')`，`spine/image/audio → addItem`，复用现有预览链路）。

### 15.1 整体布局（三区）
```
┌──────────────────────────────────────────────────────────────────────────────┐
│ ① 顶栏 .wg-toolbar                                                         │
│  [URL 输入] ▶打开 ⏹停止 ◀后退 ▶前进 ⟳刷新 🧰DevTools 🔖收藏 | 状态文本     │
├──────────────────────────────────────────────────────────────────────────────┤
│ ② 浏览器区 .wg-browser-scroll(flex,可滚动)  ←→  WebContentsView 原生叠加   │
│  ┌──────────────────────────────────────────────────────────────────┐      │
│  │ 网页在此运行；所有网络请求被自动拦截识别为资源                       │      │
│  └──────────────────────────────────────────────────────────────────┘      │
├──────────────────────────────────────────────────────────────────────────────┤
│ ③ 侧栏 .wg-side（上下分割线 #wg-hsplit 可拖动调整 ②/③ 高度比）            │
│  [📡 资源捕获 │ 🔖 网址收藏夹]                                             │
│  ├─ 资源捕获面板：类型筛选 chips + 捕获列表(类型/文件名/URL/大小/状态)     │
│  │  + 输出目录选择 + 仅下载不入库开关 + ⬇下载选中/下载全部/🗑清空 + 进度条 │
│  └─ 网址收藏夹面板：＋收藏网址 / ＋新建目录 + 分类下网址条目(打开/编辑/删除) │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 15.2 顶栏控件（①区）
| id | 名称 | 功能 |
|---|---|---|
| `#wg-url` | URL 输入框 | 输入网址（如 `https://h.api.4399.com/g.php?gameId=100073549`），回车或点「打开」 |
| `#wg-open` | ▶ 打开 | 内嵌浏览器打开 URL 并开始拦截（恢复 `webGameLastUrl`/`webGameHistory`） |
| `#wg-stop` | ⏹ 停止 | 关闭内嵌浏览器（保留捕获记录） |
| `#wg-back`/`#wg-fwd`/`#wg-reload` | ◀ ▶ ⟳ | 网页后退/前进/刷新（`webGoBack`/`webGoForward`/`webReload`） |
| `#wg-devtools` | 🧰 DevTools | 以 `openDevTools({mode:'detach'})` **独立窗口**打开网页 DevTools（Network/Console/Element，便于逆向）；右键按钮可关闭 |
| `#wg-fav` | 🔖 收藏 | 收藏当前浏览网址到收藏夹 |
| `#wg-status` | 状态文本 | 加载状态/标题/URL（`onWebStatus` 事件） |

### 15.3 浏览器区与布局
- 浏览器区：`.wg-browser-scroll` 容器，网页 WebContentsView 原生叠加其上（切页离开时 `webSetBounds({width:0,height:0})` 隐藏，防止遮挡其它页）；超限可滚动。
- 上下分割线 `#wg-hsplit`：拖动调整浏览器区与下方侧栏高度比例（改 `height` 生效，修复 flex-basis 覆盖问题）。

### 15.4 侧栏面板（③区）
两个 tab（`.wg-stab`）：
- **📡 资源捕获**
  - 类型筛选 chips（`#wg-filter`）：fgui/spine/image/audio/video/font/config/other/script 九类，点击切换显隐，配色 `typeColor`。
  - 捕获列表 `#wg-list`：实时推送（`onWebCaptured`），每行=类型徽标+文件名+URL+大小+下载状态；点击复制 URL。
  - 输出目录 `#wg-dir` + 「📁 选择」（持久化 `webGameSaveDir`）；「仅下载不入库」开关（`#wg-onlyurl`）。
  - 下载：`#wg-dl-sel` 下载选中、`#wg-dl-all` 下载全部（主进程 https 下载，rejectUnauthorized:false + Referer/UA 防盗链 + 可选代理；`onWebProgress` 进度条）；`#wg-clear` 清空捕获。
  - 入库：`downloadResource` 后本地 `probeFile` 精确分类（`.bin` 魔数 FGUII / spine json 特征），fgui `.bin → addScene(subtype='fgui')`、`spine` 自动配对同目录 `.atlas` 填 atlasPath、`image/audio → addItem`，标签 `webgame` + host。
- **🔖 网址收藏夹**
  - 工具栏：＋收藏网址 / ＋新建目录；显示当前分类名（「未分类」或分类名）。
  - 列表 `#wg-bm-list`：分类下网址条目，每行含「▶ 打开 / ✎ 编辑 / 🗑 删除」操作。
  - 数据：`web_bookmark_categories`/`web_bookmarks` 两表；支持嵌套子目录；侧栏「🔖 网址收藏夹」分类树可增删改查并联动本面板（点网址直达 `webOpenUrl`）。

### 15.5 侧栏与持久化
- 侧栏根「🌐 网络资源抓取」(`__webgame__`)：下含「🕹 最近打开」(`webGameHistory`，最多 8 条，点击回填 URL 打开) 与「🔖 网址收藏夹」(`__webgame_fav__`，可嵌套，默认展开)。根节点右键：打开抓取页 / 新建收藏夹目录 / 清空捕获记录。
- 持久化：`webGameLastUrl` / `webGameSaveDir` / `webGameProxy` / `webGameHistory`（设置项）；捕获记录跨重启保留（`webGetCaptured`）。
