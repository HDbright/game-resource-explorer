# 游戏资源管理器 — 全面布局与组件说明

> 对象：游戏资源管理器（Electron 桌面应用，v2.4.12）2026-08-24更新
> 定位：管理并预览 **动画(Spine/DragonBones/Laya .sk) / 图片(含图集) / 音频 / 视频 / 3D / 图标 / UI / 数据 / 文档** 九类游戏资源；内置资源工具箱（ASTC→PNG、SKEL→JSON、Spine 修复、Spine 格式转换、Laya .sk→Spine 逆向、图片集打包、图片编辑、FGUI 逆向导出、FGUI 编辑器、Markdown 文档、Todo-List、得乐学苑、**骨骼动画编辑器**）；游戏场景管理（含 FGUI 界面预览器）；**项目管理中心**（项目生命周期 + 服务启停 + 资源文档）；**网络资源抓取**（内嵌浏览器逆向分析并下载 FGUI/Spine/图集/图片/音频 等资源入库，支持多标签页 / 网页悬浮窗 / 资源悬浮预览窗）；**开发工具箱 → API 管理**（项目 / API 数据字典 / 接口测试 + 内嵌 API 参考文档）；网址收藏夹；**系统托盘 + 秒表/倒计时/闹钟/计时记录**；emoji 图标库；系统设置（主题外观 / 菜单管理 / 分类目录 / 页面管理 / 资源类型管理）。
> 技术栈：Electron + Vite + 原生 JS(ESM)；渲染 PixiJS 8（动画/图片/FGUI/骨骼编辑器画布，经 `src/pixiLazy.js` 动态导入）、DOM overlay（文本）、WebContentsView（内嵌网页）；独立 BrowserWindow（网页悬浮窗 / 资源悬浮预览窗 / 网址收藏对话框 / 秒表 / 倒计时 / 计时管理 / 闹钟）；数据持久化 better-sqlite3（23 张表）。
>
> 本文档上次大版本更新于 v1.9.29（2026-08-11）；v2.x 各模块细节变更见 `CHANGELOG.md`（补丁·1~149）。

## 一、应用架构与数据流

```
Electron 主进程(electron/main.js + electron/tools/* + projectRunner.js)
   ├─ 窗口/菜单/托盘/闹钟/文件对话框(shell, dialog, Tray, Notification)
   ├─ IPC 通道(db:read/write, fs:*, tool:*, fgui:*, audio:*, thumb:*, web:*, project:*, timer:*, …)
   ├─ 资源扫描(electron/scanner.js: Spine/DB/Laya .sk/图片/音频/视频/3D/FGUI/文档 识别)
   ├─ 转换工具(spine-converter C++ EXE: skel↔json 跨版本; spineProjectToJson.js: .spine 工程逆向;
   │            layaSk2Spine.js: Laya .sk 逆向; ASTC→PNG; SKEL→JSON; Spine 修复)
   ├─ FGUI 逆向(fgui/index.js: 探测/解析/导出/源工程还原) + 预览数据(previewData.js)
   ├─ 网络资源抓取(tools/webGame.js: WebContentsView 多标签 + 请求拦截 classify + 下载入库
   │              + 网页悬浮窗 floatWin + 网址收藏对话框 bookmarkDialog.js)
   ├─ 资源预览浮窗(webPreviewWindow.js) · API 测试代理(apiTest.js)
   ├─ 计时体系(tools/timerWindows.js: 秒表多实例/倒计时/计时管理/闹钟, 托盘角标)
   ├─ CDP 调试开关(tools/devCdp.js: 持久化标志 + 自动重启生效)
   ├─ 项目服务启停(projectRunner.js: 前端/后端进程 Start/Stop/Status)
   └─ SQLite 库(data/skeleton.db: items/categories/menu_nodes/toolbox_folders/todo_*/
                  projects/project_entries/time_*/alarms/web_bookmark_*/api_* 等 24+ 表)

渲染进程(src/**: main.js 入口 → state.js 状态 → ui.js 布局与导航 → pages/*.js 各页面 → preview|viewers|editor 各引擎)
   └─ index.html: 单一 #app → 顶栏 + 侧栏(资源 tabs + menuNodes 数据驱动树) + #content-panel(14 个 page 容器)
```

数据流：`state.js`(内存) ⇄ `window.api.dbRead/dbWrite`(IPC) ⇄ SQLite；所有增删改经 `saveState()` 防抖 150ms 写盘。
网络抓取数据流：`tools/webGame.js` 拦截 WebContentsView 网络请求 → `classify` 分类 → `onWebCaptured` 推送渲染进程列表 → 选中/批量 `downloadResource`(主进程 https 下载) → `addScene`(subtype='fgui') / `addItem` 入库。
**侧栏为全数据驱动**：`menu_nodes` 表 + `state.menuNodes`（内置根节点 + 用户自定义目录/终端节点/项目节点），设置页「菜单管理」可视化编辑（见 八）。

### 2.2 侧栏分类树 `#cat-tree`（menuNodes 全数据驱动，v1.9.92+）
> 侧栏由 `menu_nodes` 表驱动（`state.menuNodes`），可在系统设置「菜单管理」中增删改/排序/隐藏；资源分组扩展时自动创建对应资源根（`ensureResourceRootsForCategories`）。

- **收藏夹根** `__m_fav__`：收藏分类树（置顶，带「＋」新建收藏分类）。
- **资源根节点**（`__m_res_anim__` 等，isResource）：动画/图片/音频/3D 固定四个 + 图标/视频/UI/数据/文档内置分组 + 自定义分组根；类型主页链接 + 分类目录树（可配置「在菜单树中显示资源文件列表」，文件行直达预览）；根右键：新建目录 / 图标叠加(v2.1.1 最多 4 个) / 显示文件列表开关等。
- **分类节点**：递归展开子分类/直属条目；条目单击 → 预览（FGUI 包直达预览）；右键菜单（打开/新建目录/编辑/删除/移动/重命名/锁定…）。
- **游戏场景管理根** `__m_scene__`：场景分类树 + FGUI 界面预览入口；FGUI 包(.bin)条目点击/右键「✏️ 用FGUI编辑器打开」。
- **项目管理中心根** `__m_projects__`：项目子节点（主页汇总/详情/资源文档，详 **二十二**）。
- **网络资源抓取根** `__m_webgame__`：内嵌浏览器逆向抓取资源入口；下含「🕹 最近打开」(`webGameHistory`) 与「🔖 网址收藏夹」分类树（可嵌套，增删改查）。
- **资源工具箱根** `__m_toolbox__`：数据驱动目录树（`toolbox_folders` 表）：目录 + 内置工具链接节点，支持**拖拽排序/移动**、右键 编辑/新增/删除/移动；首次启动注入默认结构（文件格式转换分组等）。
- **开发工具箱根** `__m_devtools__`：下含「📖 API 管理」叶子 `__devtool:api`（详 **十六**）。
- **系统设置叶子** `__m_settings__`（`page:settings`）。
- **自定义节点**：用户在菜单管理中创建的目录/终端节点（终端节点可选动作：打开某工具 / 某页面 / 自定义页面 / 项目等，`toolboxToolActions()` 动态生成）。
- 树节点构造器 `makeTreeNode`：▶/▼ 箭头 + 图标 + 名称 + 数量；节点支持图标叠加与 emoji 选择面板。

### 2.3 主内容区页面容器
`index.html` 静态 14 容器（`showPage()` 切换）：`page-home` / `page-audio-home` / `page-folder` / `page-preview` / `page-toolbox` / `page-projects` / `page-scene` / `page-fgui-editor` / `page-webgame` / `page-api` / `page-atlas` / `page-settings` / `page-custom` / `page-emoji`。
- 工具箱的大模块工具（Todo-List / 得乐学苑 / 骨骼动画编辑器）**内嵌于 `page-toolbox`**，进入时隐藏工具箱头部占满主区（`toolboxPage.js`）。
- `page-custom`：自定义页面容器（网页模板 / 笔记模板，设置页「页面管理」增删改，可作终端节点目标页面 `page:custom:*`）。
- 各页职责详 三~八 与 十四~二十六。

### 2.4 主区多标签页（v1.6.9+）
- 主内容区顶部标签条 `#tab-strip`（`.main-tab`：图标 + 名称 + 悬停显示的 ×）；**右键菜单**：关闭 / 关闭其它 / 关闭右侧（v2.0.71）。
- **打开资源 = 新标签页**；点击类型/目录/工具箱/场景/设置/首页等导航 = 切换到对应标签页，原标签保留可随时切回。
- 标签 kind：`home/root/cat/folder/group/preview/atlas/emoji/projects/scene/toolbox/webgame/settings` + 自定义页；关闭当前标签自动切到相邻标签，全部关闭回首页。
- 预览页前后切换（`#pv-prev/#pv-next`，悬停画面边缘浮现）**复用当前预览标签**不堆叠（v2.0.19/32）。

## 六、资源工具箱（page-toolbox）

工具箱主页（汇总卡片视图）+ 侧栏目录树双入口；12 个内置工具（`toolboxPage.js` TOOLS 定义，菜单终端节点「目标页面」下拉由 `toolboxToolActions()` 动态生成）。**FGUI 编辑器**不是工具卡片，经工具箱侧栏目录树节点 `__fgui_editor__` 进入（详 **十四**）：

| 工具 id | 名称 | 说明 |
|---|---|---|
| `astc2png` | ASTC → PNG | 读取 `.astc`（16 字节头），软件解码转 PNG |
| `skel2json` | SKEL → JSON | Spine 二进制骨架转 JSON（3.x/4.x 两套解析） |
| `spinefix` | Spine 文件修复 | 剥 BOM/注释/尾逗号/补版本、skel 探测、atlas 检查 |
| `sk2spine` | Laya .sk → Spine | LayaAir 骨骼动画二进制逆向转换为 Spine 3.8 `.json` + `.atlas`（详 **十九**） |
| `spineconvert` | Spine 格式转换 | skel↔json 双向 + 跨版本(3.5-3.8/4.0-4.3) + `.sk`/`.spine` 输入（详 **十九**） |
| `atlas` | 图片集打包 | MaxRects 装箱合并图集，导出 PixiJS/Phaser3/Cocos2d/CSS（详 **二十三**） |
| `imageedit` | 图片编辑 | 镜像/旋转/缩放/缩略图批量处理 |
| `fgui` | FGUI 导出源 | .bin 逆向导出源工程（FGUI_src/<包名>/） |
| `markdown` | Markdown 文档 | 查看/编辑 .md（详 **二十四**） |
| `todo` | Todo-List | 任务管理（详 **二十**） |
| `kidworkspace` | 得乐学苑 | 儿童学习打卡（详 **二十一**） |
| `boneeditor` | 骨骼动画编辑器 | 复刻 LoongBones/DragonBones 编辑器（详 **十八**） |

## 二十三、图集工具（打包 + 拆分浏览）

### 23.1 图片集打包（工具箱 →「🗂 图片集打包」，src/atlasPacker.js）
- 多图合并为一张/多张纹理图集（自动分页）；**MaxRects 装箱**（Best Short Side Fit，支持旋转装箱）；透明像素修剪（trimmed/sourceSize/spriteSourceSize 与 TexturePacker 坐标约定兼容）；内边距；强制 2 的幂尺寸。
- 导出格式：**PixiJS(JSON Hash) / Phaser3(JSON Array) / Cocos2d(JSON) / CSS 雪碧图**；页面内联预览。骨骼动画编辑器的 DragonBones 导出复用此打包器。

### 23.2 图集拆分浏览（page-atlas，src/atlasView.js）
- 约定：图片 `foo.png` 与同名 `foo.atlas`（或 `foo.png.atlas`）同目录 → 图片预览页显示「🗂 图集」徽标 + 「图集拆分」按钮。
- **拆分浏览页**：按 .atlas 区块名列出每张单图及计算尺寸（支持 libgdx/Spine 与 TexturePacker/Cocos2d JSON 格式，v1.9.56）；单图右键「保存图片」按区块名提取导出；列表页右键「拆分图集」批量拆到以图集命名的目录。
- 打开图片默认进普通预览（适配窗口），不自动跳拆分页（v2.0.x 修正 .png/.jpg 行为一致）。

## 二十四、Markdown / HTML 文档编辑器（src/viewers/markdownEditor.js / htmlEditor.js）

> 双宿主：工具箱「📄 Markdown 文档」工具页 + 预览页 `#pv-markdown-view` / `#pv-html-view`（文档类资源直达）；参考 MarkText 分栏体验。

- **工具栏**：新建 / 打开 / 保存 / 另存为 / 分栏·仅预览·仅编辑切换 / 导出或复制源码 / 🔍 查找（Ctrl+F，两编辑器均有）/ MD 专属（😀 emoji / ▦ 表格 / 文字色 / 标题色）/ HTML 专属（复制源码 / 加入库）。
- **编辑区** textarea + **预览区**：MD 用 markdown-it 渲染（GitHub 风格 CSS）；HTML 用 iframe srcdoc 直接渲染（自动注入 `<base>` 指向源目录，相对路径资源可加载）。
- **查找/替换**（两编辑器一致）：编辑区选中匹配并滚动聚焦；预览区（分栏预览栏 / 仅预览模式）叠加全部匹配高亮（淡黄），当前匹配橙色醒目并滚动聚焦居中（按「源码同文本第 j 次出现 ↔ 渲染第 j 个高亮」对位）；支持区分大小写 / 全词 / 替换 / 全部替换；Ctrl+F / Esc 为编辑器级快捷键（仅预览模式可用）；MD 渲染文本无命中时降级定位所在块描边。
- **分栏同步关联**：滚动位置同步；选中文字双向联动（MD 剥标记后 TreeWalker 精确匹配；HTML 按块定位）。
- **自动存档**：编辑空闲 2.5s 自动写回（已有落盘路径时），切离编辑页强制存档；同路径重复打开保持编辑状态；未保存改动文件名后小白点（dirty）。
- **MD 增强**：插入 emoji（全局选择面板多选）/ 指定行列表格（实时预览）/ 文字色 / H1-H6 标题色（**默认分级彩色**，编辑区标题行与预览同色；可逐级自定义、一键全部不加颜色或恢复默认）；查找/替换。
- 文本可选复制（MD 预览列 / HTML 预览放开 user-select）。
