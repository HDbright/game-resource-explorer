# 游戏资源管理器 — 全面布局与组件说明

> 对象：游戏资源管理器（Electron 桌面应用，v1.6.x）
> 定位：管理并预览 **动画(Spine/DragonBones) / 图片 / 音频 / 3D(model)** 四类游戏资源；内置资源工具箱（FGUI 逆向、ASTC→PNG、SKEL→JSON、Spine 修复、图片编辑）；游戏场景管理（含 FGUI 界面预览器）；收藏夹；系统设置。
> 技术栈：Electron + Vite + 原生 JS(ESM)；渲染 PixiJS 8（动画/图片画布）、DOM overlay（文本）；数据持久化 better-sqlite3（Node `node:sqlite`）。

---

## 一、应用架构与数据流

```
Electron 主进程(electron/main.js + electron/tools/*)
   ├─ 窗口/菜单/文件对话框(shell, dialog)
   ├─ IPC 通道(db:read/write, fs:*, tool:*, fgui:*, audio:*, thumb:* …)
   ├─ 资源扫描(electron/scanner.js: Spine/DB/图片/音频/3D/FGUI 识别)
   ├─ 转换工具(ASTC→PNG、SKEL→JSON、Spine 修复)
   ├─ FGUI 逆向(fgui/index.js: 探测/解析/导出) + 预览数据(previewData.js)
   └─ SQLite 库(data/skeleton.db: items/categories/fav_*/scenes 等)

渲染进程(src/**: main.js 入口 → state.js 状态 → ui.js 布局与导航 → pages/*.js 各页面 → viewers/*.js 查看器)
   └─ index.html: 单一 #app → 顶栏 + 侧栏 + #content-panel(7 个 page 容器)
```

数据流：`state.js`(内存) ⇄ `window.api.dbRead/dbWrite`(IPC) ⇄ SQLite；所有增删改经 `saveState()` 防抖 150ms 写盘。

## 二、全局框架布局

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ 顶栏 #app-header                                                             │
│  ☰(侧栏开关 #btn-toggle-side) 品牌名(点击回首页) 面包屑 #breadcrumb          │
│  🔍搜索 #search(#search-clear)  +添加资源 #btn-add  +批量 #btn-add-batch       │
│  ⚙设置 #btn-settings   ┃ 资源标签 #resource-tabs(动画|图片|音频|3D)           │
├───────────────┬──────────────────────────────────────────────────────────────┤
│ 侧栏 #sidebar  │ 主内容区 #content-panel(七页之一)                           │
│  #cat-tree     │  page-home(资源首页) / page-audio-home / page-folder        │
│  分类树:       │  page-preview(预览) / page-toolbox(工具箱)                  │
│  ·动画/图片/…  │  page-scene(场景管理) / page-settings(设置)                 │
│  ·收藏夹       │                                                             │

└───────────────┴──────────────────────────────────────────────────────────────┘
  底部/悬浮: 音频迷你条 #audio-mini(后台播放控制) · 通知 toast · 右键菜单浮层
```

### 2.1 顶栏
| id | 控件 | 功能 |
|---|---|---|
| `#btn-toggle-side` | 侧栏开关 | 显示/隐藏侧栏（localStorage 记忆） |
| 品牌名 | 首页入口 | 点击回资源首页（`resourceTab='home'`，清空一切覆盖页状态） |
| `#breadcrumb` | 面包屑 | 当前页路径（如 资源首页 › 动画 › 某分类） |
| `#search` | 全局搜索框 | 在目录页过滤资源（名称/属性/标签）；`#search-clear` 清空 |
| `#btn-add` | + 添加资源 | 打开添加流程（文件/目录扫描识别资源类型） |
| `#btn-add-batch` | + 批量添加 | 批量导入 |
| `#btn-settings` | ⚙ 设置 | 打开系统设置页 |
| `#resource-tabs` | 资源标签 | 动画/图片/音频/3D 四个类型 tab；当前 tab 高亮，主区切到类型主页/目录 |

### 2.2 侧栏分类树 `#cat-tree`
- **类型根节点**（id=`all`，名称随 tab：动画资源/图片资源/…/资源）：类型主页链接 + 展开/折叠该类型分类目录（默认展开）
- **分类节点**：递归展开子分类/直属条目；条目单击 → 预览（FGUI 包直达预览）；右键菜单（打开/新建目录/编辑/删除/移动/重命名…）
- **未分类节点**：无分类条目
- **收藏夹根** `__fav__`：收藏分类树
- **资源工具箱根** `__tools__`：文件格式转换（astc→png / skel→json / spine 修复）、图片编辑
- **游戏场景管理根** `__scene__`：场景分类树 + FGUI 界面预览入口
- 树节点构造器 `makeTreeNode`：▶/▼ 箭头 + 图标 + 名称 + 数量

### 2.3 主内容区页面容器
`page-home` / `page-audio-home` / `page-folder` / `page-preview` / `page-toolbox` / `page-scene` / `page-settings`（`showPage()` 切换）

## 三、资源首页（page-home / global home）

| 模块 | 内容 |
|---|---|
| 标题区 | 「游戏资源管理」+ 资源总数统计 |
| 统计卡片 `#home-cards` | 动画/图片/音频/3D/总数 × 各类型占用空间；点击切到类型主页 |
| 目录快捷入口 `#home-quick-cats` | 顶级分类卡片（名称+条目数+占用），点击进入目录列表页 |
| **最近打开 `#home-recent-opens`**（v1.6.7+） | 最近打开的**资源 / FGUI 包**记录：类型徽标 + 名称 + **打开日期时间**（YYYY-MM-DD HH:mm）；点击**再次打开**（资源→预览；FGUI→FGUI 预览）；数据 `settings.recentOpens`（去重按路径、最新在前、上限 20） |
| 最近添加 `#home-recent-list` | 最近入库资源（类型徽标+名称+分类），点击预览，右键菜单 |

> 类型主页（tab=anim/image/audio/3d 且目录=全部）：该类型统计卡片 + 层级分类目录树 + 最近添加。音频类型主页 = 音频播放器主页（`page-audio-home`）。

## 五、预览页（page-preview）

顶部条：返回 `#pv-back` / 类型 `#pv-type` / 名称 `#pv-name` / 版本 / 路径 `#pv-path` / 打开目录 `#pv-open-dir` / 刷新 `#pv-reload`；下方三子视图按类型切换（`#pv-anim-view` / `#pv-image-view` / `#pv-audio-view` / `#pv-fgui-view`(旧版 FGUI)）。

### 5.1 动画预览（Spine/DragonBones，PixiJS）
- 控制条：播放/暂停 `#btn-play`、重启 `#btn-restart`、速度 `#speed-range`、缩放 `#zoom-range`+模式(`fit/100%/fixed`) `#zoom-mode`、帧导航 `#frame-*`、动画切换 `#anim-select`、背景色 `#bg-*`、显示骨骼 `#show-bones`、水平翻转 `#flip-x`、旋转 `#btn-rotate`、截图 `#pv-capture`
- 运行时路由：3.x → Spine38Player(vendor/spine38)；4.x → SpinePlayer(@pixi/spine-pixi)；DragonBones → vendor/dragonbones

### 5.2 图片查看
缩放 `#img-zoom-range`、适配/原始大小、背景色、状态栏

### 5.3 音频播放器（AudioPlayerController）
单曲/目录/播放列表队列，6 模式，变速 `#audio-rate`，ID3 编辑，迷你条 `#audio-mini`（离开预览后台播放）

### 5.4 3D 模型
占位视图（showModelPlaceholder，无内置渲染器）

## 七、游戏场景管理（page-scene）

### 7.1 场景主页
统计卡片（场景总数/文件夹/文件/目录数）+ 操作（+添加场景 / 🧩添加FGUI包 / +新建目录）+ **FGUI 界面预览入口卡** + 场景分类树 + 最近添加（右键菜单：FGUI 预览/显示/打开/编辑/删除）

### 7.2 场景目录页
工具栏（返回/标题/数量/+添加场景/🧩添加FGUI包/+新建子目录）+ 子分类卡 + 场景表格（图标/名称/路径/大小/操作：🧩FGUI预览、显示、打开、编辑、移动、删除）；**FGUI 包行点击直接打开预览**；size 缺失惰性补全

### 7.3 FGUI 界面预览子页（重点，见《docs/fgui-previewer-layout.md》）
- 三区：工具栏（14 控件）/ 画布（PixiJS + 文本 DOM）/ 右侧面板（组件列表 + 分割线 + 快照条 + 属性面板，可拖拽布局）
- 登记/解压/导出/快照/撤销历史/控制器切换/组件定位高亮

## 十二、代码结构（src/）
| 文件 | 职责 |
|---|---|
| `main.js` | 应用入口：加载 state、初始化 UI、IPC 监听 |

| `dialogs.js` | 通用对话框/菜单/通知 |
| `addFlow.js` | 添加资源流程（文件/目录扫描） |
| `thumbnails.js` | 动画缩略图服务 |
| `clipboard.js` | 复制粘贴 |
| `pages/homePage.js` | 首页（统计/最近打开/最近添加/目录快捷） |
| `pages/folderPage.js` | 目录列表页 |
| `pages/toolboxPage.js` | 资源工具箱 |
| `pages/scenePage.js` | 场景管理 + FGUI 预览子页 |
| `pages/settingsPage.js` | 设置页 |
| `viewers/*` | 动画/图片/音频/FGUI 查看器 |
| `electron/*` | 主进程、scanner、tools(fgui/skel/astc…) |
| `index.html` / `style.css` | 全局骨架与样式 |
